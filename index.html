🤖 Créer TON propre agent IA

Guide pas à pas — Astoiyous Hassani Moustoifa
Durée totale : environ 45 minutes · Coût : environ 5 €/mois

🎯 Ce que tu vas obtenir

Un assistant IA à toi, qui tourne 24h/24 sur ton serveur, que tu pilotes depuis Telegram (comme sur ton téléphone). Il saura créer des sites, écrire des documents, coder, faire des recherches…

⚠️ Avant de commencer — 2 choses à préparer

1. Une carte bancaire (pour payer le serveur ~5 €/mois)
2. Un ordinateur pour faire l'installation (après, tu utiliseras ton téléphone)

1 Louer ton serveur

Un serveur (ou « VPS ») est un ordinateur allumé en permanence, quelque part dans le monde. C'est là que ton agent IA habitera.

FournisseurPrix indicatifPour qui ?
Hetzner (hetzner.com)~4 €/mois⭐ Le meilleur rapport qualité/prix
OVH (ovhcloud.com)~5 €/moisFrançais, interface simple
Hostinger (hostinger.fr)~4 €/moisInterface très simple pour débuter

Configuration à choisir :

  • Type : le plus petit (2 processeurs / 4 Go de RAM / 40 Go de disque)
  • Système : Ubuntu 24.04 (prends bien cette version)
  • Nom : hermes-astoiyous
✅ À la fin de cette étape

Tu reçois un email avec l'adresse IP de ton serveur (ex. 123.45.67.89) et un mot de passe. Garde-les précieusement.

2 Te connecter à ton serveur

Sur ton ordinateur Windows : ouvre PowerShell (menu Démarrer → tape « PowerShell »).

Tape cette commande (remplace TON_IP par ton adresse IP) :

ssh root@TON_IP

Elle répond Are you sure you want to continue connecting? → tape yes puis Entrée.
Ensuite, tape le mot de passe reçu par email (⚠️ il ne s'affiche pas quand tu tapes, c'est normal — tape-le et appuie sur Entrée).

✅ Tu es connecté

Le texte de la console a changé (quelque chose comme root@hermes-astoiyous:~#). Tout ce qui suit se tape ici.

3 Installer Hermes

Copie cette ligne, colle-la dans la console et appuie sur Entrée :

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

L'installation prend 2 à 5 minutes. Laisse-la travailler.

Ensuite, lance l'assistant de configuration :

hermes setup

4 Choisir ton modèle IA

Ton agent a besoin d'un « cerveau » : un modèle d'IA. Tu dois t'inscrire chez un fournisseur et récupérer une clé API (une longue suite de lettres et de chiffres).

FournisseurPrixRemarque
DeepSeek (platform.deepseek.com)Très économique⭐ Recommandé pour commencer — quelques euros suffisent pour des mois
OpenRouter (openrouter.ai)Gratuit possibleCertains modèles sont gratuits

Puis dans la console :

hermes model

Choisis ton fournisseur, colle ta clé API. Fais ensuite un test :

hermes chat -q "Bonjour, présente-toi en 2 phrases"
🎉 Si l'IA te répond…

Ton agent fonctionne ! Il te reste juste à le connecter à Telegram pour l'utiliser depuis ton téléphone.

5 Connecter Telegram (pour l'utiliser sur ton téléphone)

  1. Dans Telegram, cherche @BotFather (le compte officiel avec le logo bleu ✔️)
  2. Envoie-lui : /newbot
  3. Il demande un nom (ex. « Mon Agent IA ») puis un identifiant finissant par bot (ex. astoiyous_bot)
  4. Il te donne un jeton (token) — une longue suite de caractères. Copie-le.

Dans la console :

hermes gateway setup

Choisis Telegram, colle le jeton. Puis démarre le service :

hermes gateway install
hermes gateway start
✅ TEST FINAL

Ouvre Telegram, cherche ton bot, envoie-lui « Bonjour ». S'il répond → c'est gagné, tu as ton propre agent IA ! 🚀

6 Créer ton premier site avec ton agent

Maintenant, la partie qui va te servir pour ton BTS et ta carrière. Dans Telegram, demande à ton agent :

Crée-moi un site web simple pour présenter mes compétences
en réseaux et sécurité. Je m'appelle Astoiyous, je prépare
un BTS TSRS à Mayotte. Il doit être moderne et adapté au
téléphone. Puis explique-moi comment le mettre en ligne.

Ton agent va : créer le site, te demander de valider, puis te guider pour le publier gratuitement (GitHub Pages).

💡 Le secret pour bien piloter l'IA

Plus ta demande est précise, meilleur est le résultat. Dis toujours : quoi (le type de site), pour qui (recruteurs, camarades…), le style (moderne, sobre, coloré…), et ce que tu veux y trouver.

🔒 Sécurité — 3 règles simples

1. Ne partage jamais ta clé API ni le jeton de ton bot.
2. N'utilise pas le mot de passe « root » donné par l'hébergeur : change-le.
3. Fais une sauvegarde de ton dossier /root/.hermes de temps en temps.
